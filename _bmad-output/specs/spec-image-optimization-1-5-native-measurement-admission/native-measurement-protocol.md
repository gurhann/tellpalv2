# Native Measurement Protocol Contract

## Preparation boundary and freeze

Story 1.5 specifies a proposed protocol. Story 1.6 executes only an accepted, immutable protocol/corpus/candidate/build/tool scope after its entry gates close. Freeze exact roles/devices/journeys/cache modes, control/candidate identities, ordering, repeats, counter tools, boundaries, settlement, finite deadlines/resource limits and stop/retry rules before the first batch. Changes create a new scope/version; preserve original failures and not-run rows.

Retain the parent proposal of 1 Hz process sampling plus event/allocation traces, 30 seconds without active work for settlement and at least five observations per selected control/candidate/cache-mode cell. Apply that repeat proposal separately to network-cold, disk-warm/decoded-cold and decoded-warm when selected. These are review defaults, not accepted budgets or reliability thresholds. Record actual achievable cadence, missed samples, warm variants and deviations; do not silently aggregate unlike cache states.

## Journey and cache identity

| Cache mode | Evidence required before measurement |
| --- | --- |
| Network-cold | Fresh isolated batch/account/access/profile namespace; verified absent encoded/decoded/live/pending hits; actual requests and delivered payloads recorded |
| Disk-warm / decoded-cold | Exact integrity-verified encoded files retained; matching decoded cache/listeners/live/pending owners absent; actual disk-hit/request outcome recorded |
| Decoded-warm | Exact final bounded provider/decode key retained and observed, with matching immutable content/access identity and actual hit/request outcome |

Clearing LRU counters while listeners are retained does not establish decoded-cold. Precache/display must use the same final bounded provider. A warm file or changed URL cannot bypass admission. Preserve accepted caches; experiment-only state preparation records every ownership/release step. Separate application disk cache state from HTTP/OS/network caches; uncontrolled layers stay disclosed.

Declare identical control/candidate list scroll/reversal and detail/back-overlap journeys first. Qualify rotation/window changes, text scale, URL renewal, corrupt/oversized input, offline miss, cache turnover and background/resume only where implemented and admitted. Future reader turns, listening, production account switching or protected-media features remain deferred unless separately implemented/admitted. A simulated session/pressure/fault hook is labeled synthetic and cannot stand in for real OS/account/provider behavior.

Experimental current-only/current-plus-next or one/two-decode arms require a concrete separately admitted scope; they do not establish safe preload/concurrency defaults. Interleave/randomize control/candidate order and retain the exact schedule, including failed/not-run attempts. Record viewport/logical slot, DPR, actual selected rendition/decode dimensions, fit/alignment, orientation/window state, source shortage, network/cache conditions, thermal/background state and any uncontrolled values. Preserve normal/enlarged-text framing and human inspection of lettering/diacritics, lines, gradients, color and applicable alpha/orientation. Use the parent two-axis unclamped-demand geometry; low-resolution sources cannot be qualified by upscaling.

## Timings and target-frame association

| Boundary | Required identity and interpretation |
| --- | --- |
| Start | Explicit current-image dispatch; run/cell/attempt/session generation, content/revision/rendition and provider/decode identity |
| Metadata and transfer | Independent metadata timing, response/request/retry identity, payload byte accumulation and transfer completion; no URL/header/response-body leakage |
| Encoded-ready | Admitted complete integrity-verified encoded bytes available; not decoded or painted |
| Decoded-ready | Actual matching decoded image/dimensions available; not necessarily onstage |
| First rasterized target frame | Exact onstage decoded revision/provider/attempt associated with the relevant rasterized frame; placeholder, error widget, offstage image and unrelated frames are excluded |
| Physical presentation | Separate observation only if the actual tool supports it; raster completion is not physical display presentation |

Use monotonic time for durations and event order. Record clock domain/unit/source and wall-clock timestamp separately; cross-tool timestamps require documented synchronization/calibration and uncertainty. A generic frame callback or image Future is insufficient to identify the target's raster completion. The proposal names the actual association mechanism and how stale/offstage/error callbacks are rejected. If unavailable, retain decoded/image-ready latency and set first-painted value to null with a reason.

## Transfer and storage

Count the actual selected journey's response payload bytes, request count, retries, prefetch and cache hits; mark wire/header/TLS counters unavailable if unmeasured. Name every positive denominator for candidate/control comparisons and keep growth/negative deltas. Do not combine phone/tablet variants as journey traffic, count one source as repeated baseline downloads or report all-variant storage totals as network savings. Record storage footprints separately with retained original/variant/revision identity.

## Memory, sampling and settlement

| Family | Observation contract |
| --- | --- |
| Flutter | Dart heap/external, decoded LRU entries/bytes, live/pending ownership and raster-cache counters where actually available; tool/version and scope required |
| Android | Process RSS, PSS, private dirty, native and graphics rows where available; exact tool/unit/permissions and sampling limits |
| iOS/iPadOS | Measured process footprint and available allocation/graphics counters; exact tool/unit/scope and attachment limits |
| Estimates | Width × height × 4 is one assumed SDR pixel-plane estimate; label it separately from process, transient or graphics memory |

Report each counter's idle baseline, absolute observed peak, signed peak/settled delta and absolute settled value at the specified idle boundary. Preserve negative baseline drift. Mark a skipped/unavailable capture with reason; do not fill with zero or a counter from another process/run. Overlapping counters are not summed. Disclose whether peaks are event/sampled/high-water values, their windows and unit conversions; polling and end snapshots can miss short peaks.

Record planned/actual timestamps and cadence, sample count/gaps, capture delay/failure, trace/collector CPU/wall cost and attachment state. Measure observer overhead where possible; unavailable perturbation is explicit and no invented subtraction is permitted. Record active work, pending transfers/decodes, owner releases and background/thermal changes before settlement; if the declared idle condition is not reached within its frozen limit, retain the failure rather than relabeling an active snapshot settled.

Synthetic pressure proves only the tested handler behavior. Genuine OS pressure/termination requires actual provenance, including jetsam/OS reason and page-size/unit evidence when available. A restart alone cannot establish image causation. Smaller encoded files, decode estimates and cache caps do not establish process safety or leak absence.

## Evidence record and failures

Each future raw observation binds scope/build/device/tool, source/candidate/reference/profile, role/slot/DPR/fit, account/access alias, revision/provider/decode, cache proof, run/attempt/schedule and clocks. It retains timings, actual bytes, dimensions, counter samples/boundaries, owner state, quality verdict, failure category and limitations. Private media, raw device/account identifiers, credentials and URLs remain outside tracked outputs; public receipts retain hashes and sanitized aliases.

Represent an unavailable numeric observation as a nullable value plus availability/reason/provenance. Reject boolean/nonfinite metrics, invalid units/order, forged identity and impossible byte/duration values. Keep output integrity, instrumentation adequacy, human quality and resource acceptance as separate results. A candidate may decode correctly while resource evidence is invalid; that case does not pass a resource criterion.

Retain timeout, corruption, source/profile shortage, quality rejection, excessive resource use, sampling loss, cancellation and actual termination. Retry creates a new attempt and never erases the prior failure. Integrity/admission/instrumentation stop conditions preserve remaining not-run rows. Exact retry/deadline/evidence caps belong to the later frozen batch and cannot be borrowed from Story 1.4's Python watchdogs as mobile budgets.

Publish all raw-derived observations, counts, median and min/max with the selected cell denominators and limitations. Five-observation pilots or later descriptive quantiles are not production P95, rare-crash estimates or crash-free evidence. Human native quality approval is separate from byte/latency/memory results; quality-qualified savings remain unavailable until its criteria pass. Native evidence informs OQ proposals without adopting production policies or closing unsupported roles/floor gaps.
