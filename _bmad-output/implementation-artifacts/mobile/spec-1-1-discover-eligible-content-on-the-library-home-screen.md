## Intent

**Problem:** The mobile app has only a media PoC. Readers cannot view the approved Library, and existing catalog responses lack CMS row order, audience-aware locks, explicit category content-language mapping and lightweight cover-only delivery.

**Approach:** Deliver Story 1.1 as one backend/CMS-to-Flutter slice: editable and persisted per-language Library row order, verified lightweight catalog/real covers and the reference Library under controlled test access.

## Boundaries & Constraints

**Always:** Follow the companion contract, canonical backend architecture and ADR-0018. Use feature-first Clean Architecture, BLoC/Cubit with Freezed state, auto_route and get_it/injectable. Support TR/EN/PT, Android API 24/iOS 15 and phones/tablets. Keep server-owned identity/audience, immutable context plus request-attempt identity, actual artwork and redacted evidence. Use one server-configurable preview default of five after eligibility filtering, without per-category overrides. Ordinary rows use only eligible selected-language content; deliberately labeled different-language rows carry explicit content-language identity. CMS row order is independent per language and separate from card order.

**Ask First:** Reference redesign, module edges beyond user → category::api, production mutation, signing changes or expansion into another story.

**Never:** Automatic English/other-language content substitution, client premium authorization, credential/token UI/logs/commits, production test bypass, invented thumbnail URLs, full playback payloads, parent mode, or implementing detail/search/paywall/auth/migration here. Preserve the media PoC.

## I/O & Edge-Case Matrix

| Input/state | Output | Failure handling |
| --- | --- | --- |
| Eligible configured rows | Saved CMS row order, explicit item language/artwork/free/lock and at most the shared limit of five | Empty rows omitted; filtering preserves remaining row and card order |
| Missing/unready ordinary selected-language localization | Item excluded without language substitution | Omit a row with no eligible items in its declared content language |
| Three eligible Turkish items plus two English-only versions | Three Turkish previews | No foreign-language padding |
| Deliberately labeled English row in Turkish UI | Explicit English curation/content identity and English item metadata; Turkish UI remains selected | Enforce language/test visibility, publication and audience eligibility |
| CMS changes only Turkish row order | Saved/reloaded Turkish order reaches backend/mobile | English order and within-category card order remain unchanged; save errors are recoverable |
| Subscriber test UID | ALL rows; server lock flags | NON_SUBSCRIBER rows omitted |
| Missing/invalid/unlisted token; bad language | 401/403/400 ProblemDetail | No catalog disclosure |
| Loading; empty 200; network failure | Stable geometry; localized empty; error plus retry | Distinct outcomes |
| Catalog exceeds its recorded waiting limit | Recoverable error followed by current-context retry | Invalidate the expired attempt and discard late results |
| Artwork absent, corrupt or beyond its recorded waiting limit | Defined error placeholder with geometry/title/lock retained | Other catalog items remain displayed; bounded current-attempt retry/expiry refresh |
| Old success/error/artwork/timeout after context change or same-context retry | Only current-context/current-attempt results affect state | Reject obsolete catalog and image completions, including disposal |
| Library reselected; disabled Sleep/Profile or deferred control tapped | Library stack/scroll retained and selected tab unchanged | Disabled accessibility semantics; no input/navigation/paywall action |
| Worker A callback after lease expiry and retry B starts | Current LISTING_COVER job and ready manifest unchanged | Atomically reject A completion/failure, including failure from a rejected-completion catch |
