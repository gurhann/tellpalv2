# İkinci iPhone denemesi: ek bağlam

Resmi sonuç **FAIL / DRIVER_FAILED**. Profile build geçti. Launch, **600.052 ms** sınırında sona erdi. Son log, Dart VM Service bulunamadığını gösterdi. Bunun kesin nedeni belirlenmedi. Generic Local Network açıklaması izin reddi kanıtı değildir. Kullanıcı Mac veya iPhone üzerinde izin/hata penceresi görmediğini bildirdi.

Fiziksel ölçüm **NOT_RUN**: planlanan 6 durumdan **0 kabul edilen durum**, **0 runtime örneği** ve **0 screenshot** vardır. Native decode, tam RGB eşitliği, paint, fiziksel piksel ızgarası, Dart owned-handle stop ve RSS doğrulanmadı. Ana JSON içindeki `samplesPerFormatPerAsset=1`, planlanan protokolün eski alanıdır; ölçülmüş örnek sayısı değildir. Eski rapor değiştirilmedi.

Çalıştırmadan önce seçili cihazın kilidi açıktı. Timeout sonrasında yalnız kurulu QA paketinin tam executable yoluyla eşleşen süreçler arandı: **0 eşleşme**. Stop gönderilmedi. Native süreç yokluğu, Dart kaynak bırakma ölçümü sayılmaz.

97 Flutter testi ve hedefli analyze geçti; mobile kaynakları ilk doğrulamayla aynı kaldı. Donmuş ikinci deneme öncesi ilgili Python testlerinin 23'ü geçti. Mevcut fixture ve signing çıktıları, önceki private deneme, eski kök raporlar ve `.memlog.md` hash'leri korundu.

Renderer gözlenmedi. HTTP transferi ve gerçek OS background testi yapılmadı. İnsan görsel kalite, tam genişlik reader, P0/P4b ve üretim kabulü açık. Yeni iPhone denemesi başlatılmadı. Ana rapor ve receipt hash bağları `attempt-context.json` içindedir.
